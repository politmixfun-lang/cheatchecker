# Mine Checker

Проверка компьютера игрока на читы для Minecraft. Одна программа, которую игрок
скачивает и открывает: он вводит свой ник и ник администратора, жмёт кнопку —
отчёт с находками автоматически улетает боту в Discord и/или Telegram.

Работает на **Windows** и **macOS** (Linux — частично). Система определяется
сама, набор проверок подставляется под неё.

---

## 1. Что проверяется

| Что | Как |
|---|---|
| **Известные читы** | 97 клиентов + читерские моды, инжекторы, автокликеры, чистильщики следов — 714 сигнатур |
| **Переименованные читы** | `.jar` вскрывается и читается изнутри: пакеты, классы, строковые константы. `Vape.jar` → `homework.jar` не спасает |
| **Замаскированные файлы** | `.png`, `.txt`, `.dat`, у которых внутри Java-архив с классами |
| **Новые и приватные читы** | эвристика: если в архиве найдено 5+ читерских модулей (`KillAura`, `Scaffold`, `Velocity`, `AutoTotem`…) — это чит, даже если его нет в базе |
| **Ghost-клиенты** | `Premain-Class`/`Agent-Class` в манифесте, `-javaagent:` в аргументах запуска, инъекция в живой процесс игры |
| **Папки игры** | `mods`, `versions`, `resourcepacks` (X-Ray), `shaderpacks`, `options.txt` (gamma, биндов вроде `key_killaura`), профили лаунчера |
| **Логи** | `latest.log`, архивы `.log.gz`, crash-reports — упоминания читов остаются после удаления самого чита |
| **Процессы** | что запущено прямо сейчас, полные командные строки Java |
| **Следы удаления (Windows)** | Корзина ($I-записи с путём и временем), Prefetch, Recent/LNK, JumpLists, реестр (BAM, UserAssist, MUICache, RunMRU, Compatibility Assistant), журнал USN |
| **Следы удаления (macOS)** | Корзина, база карантина (что скачивалось из интернета), Spotlight по всему диску, недавние файлы, история терминала, LaunchAgents, статус SIP/Gatekeeper |
| **Попытки замести следы** | CCleaner/BleachBit/шредеры, timestomp-утилиты, пустой Prefetch, удалённый журнал USN, пустая папка `mods`, изменённая перед самой проверкой |
| **Обход проверки** | виртуальные машины, AnyDesk/TeamViewer/Parsec, макро-ПО мышей (Bloody, G HUB, Razer) |

Ложные срабатывания погашены белым списком: Sodium, Fabric API, OptiFine, JEI,
Iris и другие обычные моды находку не создают.

## 2. Готовая программа

`MineChecker.app` (macOS) уже собран и лежит в корне проекта — двойной клик, никаких
доп. файлов и Python не нужно. `dist/MineChecker.zip` — та же программа, упакованная
для отправки игроку.

Куда слать отчёты, можно указать **прямо в окне**: кнопка **⚙ Куда слать отчёт** →
вписать webhook Discord и/или токен Telegram → **Проверить отправку** (придёт тестовое
сообщение) → **Сохранить**. Настройки лягут в `~/MineChecker/config.json`.

Но игроку эти настройки не передать — у него будет свой пустой файл. Поэтому
**для раздачи игрокам** соберите программу со своими данными: шаги ниже.

---

## 3. Сборка своей версии (для администратора)

### Шаг 1. Настроить, куда слать отчёты

```bash
cp config.example.json config.json
```

и вписать в `config.json` свои данные:

```jsonc
{
  "discord": {
    "enabled": true,
    "webhook_url": "https://discord.com/api/webhooks/…",   // Настройки канала → Интеграции → Вебхуки
    "mention_role_id": ""                                   // ID роли, которую пинговать при находке
  },
  "telegram": {
    "enabled": true,
    "bot_token": "123456789:AA…",   // от @BotFather
    "chat_id": "-1001234567890"     // ID чата/канала, куда пишет бот
  }
}
```

### Шаг 2. Собрать один файл

Три способа — выбирайте по тому, что есть под рукой.

#### А. Есть Windows

Двойной клик по **`build_windows.bat`**. Он сам поставит Python (через winget или
установщик с python.org), сам поставит PyInstaller и customtkinter, сам соберёт.
Результат: **`dist\MineChecker.exe`** — один файл, Python игроку не нужен.

#### Б. Windows нет — собрать `.exe` через GitHub (бесплатно)

В проекте лежит готовый workflow [`.github/workflows/build.yml`](.github/workflows/build.yml).

1. Создайте пустой репозиторий на GitHub (можно приватный).
2. В папке проекта:

```bash
git init && git add -A && git commit -m "mine checker" && git branch -M main && git remote add origin ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ && git push -u origin main
```

3. На GitHub: вкладка **Actions** → слева **«Сборка MineChecker»** → кнопка **Run workflow**.
4. Через ~3 минуты внизу страницы запуска, в разделе **Artifacts**, появятся
   **`MineChecker-Windows`** (`.exe`) и **`MineChecker-macOS`** (`.zip`).

> `config.json` в `.gitignore` — свои webhook и токен в публичный репозиторий не
> попадут. Тогда сборка возьмёт `config.example.json`, и настройки игрок задаст
> в окне. Хотите вшить свои — уберите `config.json` из `.gitignore`, но держите
> репозиторий приватным.

#### В. macOS

```bash
python3 build.py
```

Результат: **`dist/MineChecker.zip`** (внутри `MineChecker.app`) — это и отправляйте игроку.

> `config.json` вшивается **внутрь** программы при сборке, поэтому игрок ничего
> не настраивает: открыл, ввёл ники, нажал кнопку.

### Шаг 3. Отдать файл игроку

Он открывает программу, вводит два ника, ставит галочку согласия и жмёт
**«НАЧАТЬ ПРОВЕРКУ»**. Через 1–3 минуты отчёт приходит вам в бота.

## 4. Запуск из исходников (без сборки)

```bash
python3 main.py
```

или двойным кликом: `start.command` (macOS) / `start.bat` (Windows).

Консольный режим:

```bash
python3 main.py --cli --player Steve --admin Notch
python3 main.py --cli --player Steve --admin Notch --no-send   # без отправки
```

Зависимостей нет — всё на стандартной библиотеке. `customtkinter` ставится по
желанию, только ради скруглённых контролов; без него интерфейс рисуется на
обычном tkinter в той же тёмной теме.

## 5. Что видит администратор

**В боте** — карточка с вердиктом, ником игрока, ником администратора, системой,
счётчиками находок, топ-10 самых важных и прикреплённым файлом отчёта.

**В файле отчёта** — по каждой находке: что нашли, почему это важно, полный путь,
размер, SHA-256, время создания/изменения/последнего доступа.

Отчёты сохраняются в трёх форматах:

| Формат | Зачем |
|---|---|
| `.txt` | уходит в бота, читается где угодно |
| `.html` | тёмная страница со сворачиваемыми карточками — открыть и разобрать спокойно |
| `.json` | для архива и своей автоматизации |

Куда сохраняются: рядом с программой в `reports/`, а у собранной версии —
`~/MineChecker/reports/` (папка открывается кнопкой из окна).

### Вердикты

| Вердикт | Когда |
|---|---|
| 🟢 **ЧИСТО** | ничего не найдено |
| 🔵 **СЕРАЯ ЗОНА** | Litematica, Xaero's Map, JourneyMap — запрещены не везде |
| 🟡 **ПОДОЗРИТЕЛЬНО** | нужна ручная проверка |
| 🟠 **СЛЕДЫ ЧИТОВ** | чита нет, но система помнит, что он был |
| 🔴 **ЧИТЫ НАЙДЕНЫ** | проверка провалена |

## 6. Права администратора

Часть журналов Windows (**Prefetch**, **USN**, **BAM**) читается только с
повышенными правами. Без них проверка работает, но следов удалённых файлов
найдёт меньше — окно честно об этом предупреждает.

Просите игрока запускать через **ПКМ → Запуск от имени администратора**.

## 7. Настройки `config.json`

```jsonc
"scan": {
  "deep_jar_scan": true,     // вскрывать .jar изнутри (главная защита от переименований)
  "max_jar_size_mb": 400,    // потолок размера архива для глубокого разбора
  "max_depth": 6,            // глубина обхода папок
  "usn_journal": true,       // читать журнал USN (Windows, нужен админ)
  "spotlight": true,         // искать через Spotlight (macOS)
  "extra_paths": []          // дополнительные папки, например ["D:\\Games"]
}
```

## 8. Как добавить новый чит в базу

Всё в одном файле — [`checker/signatures.py`](checker/signatures.py):

```python
"Название": {
    "sev": "critical",           # critical / high / medium / low
    "cat": CAT_CLIENT,           # CAT_CLIENT, CAT_GHOST, CAT_MOD, CAT_BEDROCK…
    "aliases": ["как называют файл", "альтернативное имя"],
    "markers": ["me/автор/клиент", "ИмяКласса"],   # строки внутри .jar
},
```

`aliases` ловят чит по имени файла, `markers` — по содержимому, даже если файл
переименован. Чтобы найти маркеры: распакуйте `.jar` и посмотрите структуру
пакетов.

Новые читерские функции добавляются в список `HEUR_MODULES` — тогда эвристика
начнёт ловить и те клиенты, которых ещё нет в базе.

## 9. Границы

* Проверка **добровольная и открытая**: без галочки согласия кнопка не работает,
  игрок видит список того, что смотрится и куда уходит отчёт.
* Личные документы, переписки, пароли, история браузера не читаются и не
  отправляются — в отчёт попадают только совпадения с сигнатурами.
* Инструмент **не заменяет** серверный античит и живой скриншер: он ищет следы
  на диске, а не подтверждает игру с читом. Итоговое решение — за администратором.
* Скомпилированный `.exe`/`.app` не подписан сертификатом, поэтому SmartScreen
  (Windows) и Gatekeeper (macOS) при первом запуске покажут предупреждение.
  На macOS: **ПКМ по программе → Открыть → Открыть**.

## Антивирус ругается на программу

Это ложное срабатывание, и оно ожидаемо. Причина не в коде, а в двух вещах сразу:

1. **PyInstaller.** Сборка «в один файл» при каждом запуске распаковывает себя во
   временную папку и запускает код оттуда. Ровно так ведут себя дропперы, поэтому
   эвристики Defender и подобных на это реагируют.
2. **Что делает сам чекер.** Он перечисляет процессы, читает реестр (BAM,
   UserAssist), Prefetch и обходит диск. Это поведение разведывательного ПО —
   антивирус не отличает «легальный скринчекер» от «инфостилера» по действиям.

### Что уже сделано в сборке

| Мера | Зачем |
|---|---|
| `--noupx` | UPX-упаковка — самый частый повод пометить файл как упакованный вредонос |
| Ресурс версии (`CompanyName`, `ProductName`, описание) | безымянный бинарник без метаданных подозрителен сам по себе |
| Иконка и осмысленное имя файла | то же самое |
| Никакой обфускации и шифрования | обфусцированный код почти гарантированно ловит эвристику |

### Что даёт самый большой эффект

**Собрать папкой, а не одним файлом:**

```bash
python3 build.py --dir
```

Получится `dist/MineChecker.zip` — внутри папка с `MineChecker.exe`. Скачивать
игроку по-прежнему один файл, но при запуске программа ничего не распаковывает
во временную папку, и претензий у антивируса становится сильно меньше.

**Подписать сертификатом.** Это единственное, что убирает и предупреждение
SmartScreen, и большинство ложных срабатываний. Нужен сертификат для подписи кода
(OV — примерно 200–400 $ в год, EV даёт репутацию в SmartScreen сразу). Самоподписанный
сертификат здесь не помогает вообще. Подпись:

```bash
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a MineChecker.exe
```

**Отправить файл в Microsoft как ложное срабатывание** — бесплатно, обычно
исправляют за 1–3 дня: <https://www.microsoft.com/en-us/wdsi/filesubmission>
После этого Defender перестаёт ругаться у всех.

### Что сказать игроку

* SmartScreen: **«Подробнее» → «Выполнить в любом случае»**.
* Если Defender удалил файл: Безопасность Windows → Защита от вирусов → Журнал
  защиты → разрешить, либо добавить папку в исключения.

Проверить, что файл чистый, можно самому: загрузите `.exe` на
<https://www.virustotal.com> — у неподписанной PyInstaller-сборки обычно
срабатывают несколько мелких движков из семидесяти, и это нормально.

> Чего в программе намеренно **нет**: обфускации, шифрования полезной нагрузки,
> антиотладки и прочих приёмов сокрытия. Они бы не помогли пройти антивирус, а
> сделали бы только хуже — и превратили бы честный инструмент в то, чем он не является.

## 10. Структура проекта

```
main.py                     точка входа (окно / --cli)
build.py                    сборка в один файл
build_windows.bat           то же для Windows одним кликом
config.example.json         шаблон настроек
assets/make_icon.py         генератор иконки (без внешних библиотек)
checker/
    signatures.py           база: 97 клиентов, моды, инжекторы, макросы, эвристика
    platform_info.py        определение ОС, поиск папок Minecraft и корней сканирования
    engine.py               оркестратор проверки + дедупликация находок
    report.py               вердикт, .txt / .html / .json
    senders.py              Discord webhook, Telegram Bot API
    gui.py                  три экрана: ввод → прогресс → результат
    ui_kit.py               прослойка customtkinter / tkinter
    utils.py                матчер сигнатур, обход ФС, хеши
    scanners/
        files.py            имена файлов и папок, маскировка расширений
        jars.py             разбор .jar изнутри
        minecraft.py        mods, versions, профили, ресурспаки, логи
        processes.py        запущенные процессы
        traces_windows.py   Корзина, Prefetch, реестр, USN
        traces_macos.py     Корзина, карантин, Spotlight, история терминала
```
